# U-Net Colorization with Perceptual Loss Project


## 1. what we implemented
We implemented the **U-Net architecture** and applied it to **image colorization on CIFAR-10** in Phase 2 project. In the Phase 3 project, we built on our previous work and implemented perceptual loss introduced in the Unreasonable Effectiveness of Deep Features as a Perceptual Metric paper as a new metric for the colorization task. 


## 2. files explanations
### Part 1: 
### UNet.py 
1. in UNet.py we implemented the U-Net architecture introduced in the UNet paper

### training.py 
1. training.py includes the training process where it's using gradient descent, a loss function, and these are all wrapped up in the run_model method
2. it also has a visualize method that generates the input, prediction, and target images for the first 3 images in the first batch of the test dataset

### Part 2: 
### data.py
1. build dataset and dataloaders
2. convert CIFAR-10 into (grayscale, color) pairs
3. split into train/validation/test set

### Part 3: 
### perceptual_loss.py
1. the perceptual_loss method implements the perceptual metric introduced in the paper
2. the perceptual_loss_simp method doesn't use the outputs from intermediate layers as in the paper, and instead it uses the final output from the neural network as a simpler version of the paper's original implementation

### Part 4: 
### hyperparameter.py
we implemented experiments on:
1. **perceptual layers**: select specific perceptual layers of CIFAR-10 VGG-19
2. **mse weights**: select different mse weigths for loss function

### flower_hyperparameter.py
we implemented experiments on:
1. **perceptual layers**: select specific perceptual layers of ImageNet VGG-19
2. **mse weights**: select different mse weigths for loss function
3. **learning rate**: select different learning rates for the experiment

## 4. reproduce the reported figures/tables
### Part 3: 
1. Figure 1. Qualitative comparison of the paper's implementation using intermediate layers' outputs vs the simpler version is produced by calling the visualize method from training.py, replacing the loss function as one of the two types in perceptual_loss.py \
   **command:** ran the model on Jupyter notebook by just running the 2 blocks in run.ipynb
   **expected output:** 9 images for the first 3 examples in the test dataset and it has input, prediction, and target images for each example (3*3): the folder figures/qualitative results/extraction or simple only contains the 3 prediction images for each type of perceptual loss
   
2. The top 2 plots in Figure 2 are generated during the training process and are directly screenshoted from jupyter notebook. The third plot that compares the losses from the 2 types of perceptual loss designs is generated by first copying the losses generated during training into the lists in plot.py and then calling the plot_loss_comp method with the corresponding parameters\
   **command:** python plot.py\
   **expected output:** a line chart: figures/qualitative results/loss_comp.png
